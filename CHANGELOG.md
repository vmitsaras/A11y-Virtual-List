# Changelog

## 1.0.0 - 2026-08-04

### Added

- Accessible, framework-agnostic virtual list rendering for large datasets with fixed and estimated row-height modes.
- Native, roving `aria-activedescendant`, and listbox navigation modes with keyboard and pointer activation.
- Focus preservation, stable-key item updates, scroll-position persistence, and predictable teardown behavior.
- Debounced visible-range announcements, item position metadata, and lifecycle events for application integrations.
- TypeScript declarations, ESM package exports, baseline accessible styles, documentation metadata, and example pages.
- Automated coverage for initialization, virtualization, navigation, focus recovery, updates, lifecycle events, and package entry points.
