# Security Policy

## Supported Versions

No version has been released yet. Security support begins with the initial npm
release; after that, the latest published version will receive security fixes.

## Reporting A Vulnerability

Use GitHub's **Report a vulnerability** option on the repository's Security tab
when it is available. This keeps the report and any proof of concept private.

If private vulnerability reporting is not available, open a minimal issue that
asks the maintainer to establish a private reporting channel. Do not include
exploit details, credentials, personal data, or a proof of concept in that
public issue.

Include the affected version or commit, impact, reproduction conditions, and a
suggested mitigation when known. Please allow the maintainer time to confirm the
report and coordinate a fix before public disclosure.
